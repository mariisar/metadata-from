# Data Analysis and Technical Support Portal

A responsive web portal designed for the **Data Analysis and Technical Support Section** of the Office of the NBTC. This platform serves as a centralized hub for data management, policies, manuals, data dictionaries, and structural workflows.

## 🚀 Key Features

- **Dashboard:** Overview of agency data registration metrics and analytics.
- **Data Agent:** Directory and management tools for organizational Data Agents.
- **Data Structure & Metadata:** Step-by-step guidance on data structure implementation and metadata registration forms.
- **Policy & Manuals:** Centralized repository for official announcements, guidelines, and user manuals.
- **Data Owner & Knowledge Hub:** Tracking data ownership and resource sharing.
- **Integrated Services:** Quick access links to Data Catalog, Data Center, and Open Data platforms.

## 🛠️ Technology Stack

- **HTML5 / CSS3 / JavaScript (Vanilla JS)**
- **Responsive Layout & Modern CSS Variables** (Supports light/dark themes and secure-area-inset adaptation)
- **Zero-Dependency Architecture:** Lightweight and fast-loading single-file / multi-view component layout.
